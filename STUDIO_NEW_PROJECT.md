# Studio: start an empty project

Version 0.41.0 adds a full-width **+ New project** action above the Studio library. It immediately saves a separate draft and opens an empty editing workspace; importing a video is no longer required to create a project.

The empty workspace offers Add video, Photo, Audio and Text. Existing projects remain available in the horizontal project rail. Empty drafts can be reopened, and activity recreation restores the empty workspace. Adding the first visual asset opens the normal editor. Deleting the final visual asset returns to the empty project rather than sending the user out to the library. Audio imported before a visual asset is retained in the draft.

Validation: debug assembly and Android lint pass. Installed on the connected TECNO. Device interaction coverage is pending while the phone is being used for recording.
