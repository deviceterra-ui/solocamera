Media3 CompositionPlayer 1.8.0 source (Copyright 2024 The Android Open Source Project, Apache License 2.0) is included under app/src/main/java/androidx/media3/transformer. Modified October 2026 to bound each sequence's load-control buffer to 4 MiB and 2.5 seconds; optional compile-time analysis annotations are omitted. The matching local transformer AAR excludes only CompositionPlayer and its nested classes so they are compiled from this source. All other transformer implementation classes are unchanged. Original source: https://github.com/androidx/media/blob/1.8.0/libraries/transformer/src/main/java/androidx/media3/transformer/CompositionPlayer.java .

ExoPlayerAssetLoader 1.8.0 is also compiled from the original Apache-licensed source with its loader buffers bounded to 4 MiB / 2.5 seconds. Its class and nested classes are excluded from the paired local AAR. This protects multi-track Transformer preview and export from the original per-input 50-second buffer budget.

Binary app/libs/jump3r-1.0.5.jar, complete corresponding source vendor/mp3/jump3r-1.0.5-sources.jar, license app/src/main/assets/licenses/jump3r-LGPL-2.1.txt. The Android adapter uses the encoder core and does not use desktop javax.sound APIs. Replace the unmodified library JAR and rebuild the app to use a modified encoder. No DRM or integrity restriction prevents replacing the encoder in a rebuilt app.
